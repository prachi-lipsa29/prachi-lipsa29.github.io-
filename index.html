03 / Projects

Things I've built

September 2025 — Smart India Hackathon 2025 (Software Edition)

Nexus Vault 2.0 — Hybrid Attendance System

Overview

A hybrid attendance system built for Smart India Hackathon 2025 (Software Edition), combining RFID authentication with computer-vision-based face recognition for cross-verified attendance.

Problem & solution

Single-method attendance systems (RFID-only or vision-only) are each easy to spoof on their own. This project cross-verifies RFID and facial recognition, with a dual local–cloud pipeline that keeps working offline and syncs automatically once connectivity returns.

Technologies

ESP32-CAM RFID Computer Vision Face Recognition Cloud Sync

Key features

  • Real-time facial capture via ESP32-CAM
  • Cross-verification between RFID and face recognition
  • Dual local–cloud pipeline with offline operation and auto-sync
  • Scalable authentication modes — RFID-only, Vision-only, or Hybrid
December 2025

Smart Ergonomic Study Desk

Overview

An Arduino-based smart study desk that keeps track of posture, adjusts lighting, and logs study sessions — built to make long study hours a little healthier.

Problem & solution

Long desk sessions tend to come with poor posture and inconsistent lighting. The desk uses ultrasonic and LDR sensors to detect posture and ambient light, an RTC module to track study duration, and audio-visual alerts to nudge better habits in real time.

Technologies

Arduino Ultrasonic Sensor LDR Sensor RTC Module Embedded Systems

Key features

  • Posture monitoring
  • Adaptive lighting
  • Real-time study tracking
  • Audio-visual notifications
